# DIRTLINE MX audio pack

This build now includes a first-pass original synthesized audio pack.

## Included folders
- `audio/sfx/` — gameplay one-shots
- `audio/engine/` — seamless engine loops used by the runtime mixer
- `audio/music/` — menu theme + course race loops

## Notes
- These are original synthesized placeholder/game-ready assets, not licensed commercial recordings.
- The audio system loads them automatically through `scripts/AudioManager.gd`.
- You can still replace any file later with higher-end generated or recorded assets using the same filenames.
