# Arcade 3.0 design direction

The player races left-to-right, but the track has five depth lanes. UP TRACK moves one lane farther from the camera; DOWN TRACK moves one lane nearer. Lane selection is used for passing, obstacle avoidance and choosing lane-specific ramp lines.

Throttle and brake control speed. Lean Back and Lean Forward control wheelies and airborne pitch. Optional phone tilt can assist or fully control pitch. The camera is intentionally oblique so lane depth remains visible while jumps still read clearly from the side.
