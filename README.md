# DIRTLINE MX Arcade 3.2

A landscape Android arcade motocross game built in Godot 4.3. Arcade 3.2 is the turnkey presentation build: five-line 2.5D racing, phone-tilt/lean jump control, medium-poly textured environments, upgraded rider/bike art, and a complete branded front-end.

## 3.2 highlights
- Professional DIRTLINE MX logo and launcher icon
- Splash, loading, main menu, garage, settings, how-to-play, pause, and results screens
- Arcade Race and functional solo Time Trial modes
- Five rideable track lines with UP/DOWN movement
- Reworked race HUD and mobile control layout
- UI click/confirm audio
- Updated track branding textures
- Medium-poly textured Pine Ridge, Red Mesa, and Quarry Run scenery

The Android package remains `com.carl.dirtlinemx.arcade30`, so 3.2 updates the existing Arcade 3.x app.
