# DIRTLINE MX Arcade 3.1 — Medium-Poly Environment Pass

This build replaces the lightweight background silhouettes used by Arcade 3.0 with actual medium-poly textured GLB environment clusters.

## Pine Ridge
- 13,422 background triangles per cluster
- UV-mapped rock ridge, snow caps, 30 multi-tier pine trees, textured trunks/foliage and boulders

## Red Mesa
- 8,510 background triangles per cluster
- textured geological strata, mesas, boulders and cactus geometry

## Quarry Run
- 9,978 background triangles per cluster
- textured quarry walls, stepped benches, stockpiles and rock fields

All three assets use embedded PBR base-color textures and roughness materials. Editable source texture maps are also kept under `textures/backgrounds/`.

The existing five-lane 2.5D gameplay, Arcade V4 rider/bike, jumps, tilt control and track collision system are retained.
