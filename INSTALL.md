# Install

Use the Arcade 3.2 update ZIP when upgrading an existing Arcade 3.x repository. Use the fresh-install ZIP when replacing a repository from scratch.

GitHub Actions workflow: `Validate and Build DIRTLINE MX Arcade 3.2 APK`

Successful Android artifact: `DIRTLINE-MX-Arcade-3.2-Android`

Android package: `com.carl.dirtlinemx.arcade30`
